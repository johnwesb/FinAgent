# Code of Conduct

We want FinQDesk to be a welcoming, harassment-free project for everyone.
This project also follows the WeMakeDevs Code of Conduct for the
Graph Hacks hackathon.

## Our standards

Expected: respectful and constructive communication, welcoming newcomers,
accepting feedback gracefully, and focusing on what is best for the project.

Unacceptable: harassment, insults or personal attacks, discriminatory language,
publishing others' private information, and other conduct that would
reasonably be considered inappropriate in a professional setting.

## Enforcement

Maintainers may remove, edit, or reject comments, commits, issues, and other
contributions that violate this Code of Conduct, and may temporarily or
permanently ban contributors for behavior they deem harmful.

Report concerns privately via a GitHub
[security advisory / private message to the maintainers](../../security/advisories/new)
or by contacting a maintainer through their GitHub profile.
